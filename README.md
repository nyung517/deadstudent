# deadstudent

Dropout-risk screening for a limited advising budget. The model ranks students after the
first semester so that a fixed number of advising slots can be filled before the second
semester starts.

## Data

UCI Machine Learning Repository, *Predict Students' Dropout and Academic Success* (ID 697).
4,424 students, 36 columns, no missing cells. License: CC BY 4.0.
Raw file: `data/raw/data.csv` (semicolon separated).

Source: https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success

## Environment

Python 3.12 through uv. Library versions are pinned in `pyproject.toml`:
scikit-learn 1.5.2, pandas 3.0.3, matplotlib 3.10.6.

```
uv sync
uv run python scripts/prepare_data.py
uv run python scripts/make_eda.py
```

## Layout

```
data/raw/data.csv            raw download, untouched
data/processed/              train/valid/test csv files, regenerated by scripts
src/deadstudent/data.py      loading, column normalisation, binary target, split
src/deadstudent/features.py  feature groups and preprocessing
scripts/                     runnable steps, in order
artifacts/figures/           report figures
```

## Reproducibility

The split is stratified on the binary target with `random_state=42`, 60/20/20.
All preprocessing statistics are fitted on the training part only. Second-semester
columns are excluded everywhere, so every feature is known before the second semester
starts. Running the two scripts above regenerates the same split and figures.
